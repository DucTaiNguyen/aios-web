## 🧠 Overview

AIOS is a real-time evolving system that simulates dynamic state changes over time.

Each request represents one evolution step of the system.

---

## 📊 Core State

System operates with 3 main variables:

- ⚡ Energy → activity level
- 🧠 Awareness → accumulated state
- 🔁 Feedback → internal adjustment
- ⏱ Time → evolution step

---

## 🛰 Architecture

Frontend → API → Evolution Engine → JSON State
